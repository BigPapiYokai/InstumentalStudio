# StemCraft Studio

StemCraft Studio is an all-in-one instrumental creation and AI stem separation suite built with Python and PySide6.

## Features
- **Audio Import & Export**: Compatible with MP3, WAV, FLAC, OGG, M4A/AAC, AIFF, and more.
- **AI Stem Separation**: Powered by Demucs (with GPU acceleration) and ONNX backends to remove vocals or isolate drums, bass, and vocals.
- **Stem Mixer**: Adjust individual stem volumes, mute/solo, and blend vocal removal strength.
- **BPM & Tempo Control**: Pitch-preserving time stretch.
- **DSP & Effects**: 4-band parametric EQ, compressor, limiter, normalization, fades, and interactive volume envelope drawing.
- **Interactive Waveform GUI**: Zoom, pan, playhead scrub, and region selection.
